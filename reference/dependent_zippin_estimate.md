# Calculate Dependent Double Observer (Zippin) Estimate

Calculate Dependent Double Observer (Zippin) Estimate

## Usage

``` r
dependent_zippin_estimate(both, obs1_only, obs2_only)
```

## Arguments

- both:

  Integer vector of numbers of groups seen by both observers

- obs1_only:

  Integer vector of numbers of groups seen by Observer 1 (Primary) only

- obs2_only:

  Integer vector of numbers of groups seen by Observer 2 (Secondary)
  only

## Value

A numeric vector of the estimated total number of groups (\\G\_{est}\\)
