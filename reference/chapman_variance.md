# Calculate Variance of the Chapman estimator

Calculate Variance of the Chapman estimator

## Usage

``` r
chapman_variance(both, obs1_only, obs2_only)
```

## Arguments

- both:

  Integer vector of numbers of groups seen by both observers

- obs1_only:

  Integer vector of numbers of groups seen by Observer 1 only

- obs2_only:

  Integer vector of numbers of groups seen by Observer 2 only

## Value

A numeric vector describing the variance of the estimated number of
groups
