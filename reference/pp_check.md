# Graphical Posterior Predictive Checks for DOAS Bayesian Models

Leverages the `bayesplot` package to produce graphical posterior
predictive checks (PPC) for
[`doas`](https://achazhardenberg.github.io/DOAS/reference/doas.md)
Bayesian models. Compares observed survey counts \\y\\ against
replicated datasets \\y\_{\text{rep}}\\ generated by
[`posterior_predict`](https://achazhardenberg.github.io/DOAS/reference/posterior_predict.md).

## Usage

``` r
pp_check(object, ...)

# S3 method for class 'doas'
pp_check(
  object,
  type = c("dens_overlay", "stat", "stat_2d", "bars", "intervals", "ribbon", "rootogram"),
  n_draws = 50,
  stat = "mean",
  target = c("count", "both", "obs1", "obs2"),
  ...
)
```

## Arguments

- object:

  A `doas` model object fitted with `method = "Bayes"`.

- ...:

  Additional arguments passed to the underlying `bayesplot::ppc_*`
  function.

- type:

  Character string specifying the plot type:

  - `"dens_overlay"`: Density overlay of observed data and multiple
    \\y\_{\text{rep}}\\ draws.

  - `"stat"`: Distribution of a test statistic across
    \\y\_{\text{rep}}\\ with the observed statistic marked.

  - `"stat_2d"`: Joint scatterplot of two test statistics across
    \\y\_{\text{rep}}\\.

  - `"bars"`: Bar plot comparing observed vs simulated count frequencies
    (ideal for zero-inflation).

  - `"intervals"`: Medians and central posterior predictive intervals by
    sector.

  - `"ribbon"`: Ribbon plot of predictive intervals across sectors.

  - `"rootogram"`: Hanging rootogram comparing observed vs predicted
    counts.

- n_draws:

  Number of posterior predictive draws to display (for types like
  `"dens_overlay"`). Default 50.

- stat:

  Character string or function for the test statistic when
  `type = "stat"`. Default `"mean"`. Common choices: `"mean"`, `"sd"`,
  `"max"`, `"min"`, or custom function.

- target:

  Character string specifying the observation target: `"count"`
  (default), `"both"`, `"obs1"`, `"obs2"`.

## Value

A `ggplot` object produced by `bayesplot`.
