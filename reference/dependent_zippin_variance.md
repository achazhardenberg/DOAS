# Calculate Variance of the Dependent Double Observer (Zippin) estimator

Calculate Variance of the Dependent Double Observer (Zippin) estimator

## Usage

``` r
dependent_zippin_variance(both, obs1_only, obs2_only)
```

## Arguments

- both:

  Integer vector of numbers of groups seen by both observers

- obs1_only:

  Integer vector of numbers of groups seen by Observer 1 (Primary) only

- obs2_only:

  Integer vector of numbers of groups seen by Observer 2 (Secondary)
  only

## Value

A numeric vector describing the variance of the estimated number of
groups
