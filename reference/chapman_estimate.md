# Calculate Chapman-adjusted Lincoln-Petersen estimate

Calculate Chapman-adjusted Lincoln-Petersen estimate

## Usage

``` r
chapman_estimate(both, obs1_only, obs2_only)
```

## Arguments

- both:

  Integer vector of numbers of groups seen by both observers

- obs1_only:

  Integer vector of numbers of groups seen by Observer 1 only

- obs2_only:

  Integer vector of numbers of groups seen by Observer 2 only

## Value

A numeric vector of the estimated total number of groups (\\G\_{est}\\)
